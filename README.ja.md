# FabCafe Tokyo 1Fマップ

[English](README.md) · **日本語**

FabCafe Tokyo（1F・2F・10F）の配置図ツールです。イベントのレイアウトを作って、A4で印刷できます。

**開く:** https://kalenw-loft.github.io/fabcafe-1f-map/

## できること

- **レイアウトを作る:** プリセット（通常営業、トーク約50名、奥半面トーク、ワークショップ、朝会、空）から始めて、机・椅子・ゾーン・メモをドラッグ・回転・追加します。席数・テーブル数・立ち見の目安はその場で更新され、壁や他の家具と重なったものには印がつきます。プリセットを直すときは、横の✎（または「＋ 新しいプリセット」）を押して配置し、「保存」「別名で保存」「キャンセル」を選びます。変更したプリセットはこのブラウザに残り、「プリセットの管理…」→「プリセットのコードをコピー」で他の人に送れます。
- **印刷する:** 「印刷用PDF」で、印刷するページをプレビューを見ながら選べます。
  1. **配置図:** レイアウトと凡例
  2. **片付け用：通常営業の配置:** 元に戻すときに使います
- **貼り紙:** 「機材の上に飲み物を置かないでください」の貼り紙（A4横）
- **レイアウトを共有する:** 「共有」→「レイアウトのリンクをコピー」で、配置がそのまま開くリンクを送れます（または「レイアウトコードをコピー」→相手が「貼り付け・読み込み」）。
- **PDFを保存する:** 「印刷用PDF」でA4のPDFファイルを直接ダウンロードします（印刷ダイアログなし）。

データはすべてお使いのブラウザ内（ローカルストレージ）に保存されます。アカウント登録、サーバー、トラッキングはありません。

## AIエージェント・スクリプト向け

- `…/#floor=1F&layout=<コード>` で配置を直接開けます（「レイアウトのリンクをコピー」のリンク）。
- ページ内：`FC_MAP.switchFloor('10F')`、`FC_MAP.loadCode(text)`、`FC_MAP.layoutCode()`、`FC_MAP.layoutLink()`。
- `FC_PRINT.savePDF(['map', 'restore'])` でA4 PDFをダウンロード（必要なページを指定）。

## ヒント

- 印刷はA4、**倍率100%（実際のサイズ）**で。
- 保存したレイアウトはブラウザごとに残ります。別のパソコンで使うときは「共有」を使ってください。
- 配置図は2026年2月の図面（1:100）をなぞったもので、誤差は10cm程度です。狭い場所は現地で確認してください。

## 開発者向け

必要なのはPython 3だけです（テストを動かすときだけNodeが必要です）。

```
python3 build.py      # index.html（とClaudeアーティファクト用の fabcafe-1f-map.html）を作ります
node check.mjs        # 動作テスト（jsdomが必要：npm i jsdom）
```

| ファイル | 内容 |
|---|---|
| `editor.html` | マップエディタ：キャンバス、プリセット、保存、共有、貼り紙 |
| `plan-data.js` | 1Fの形状（mm）：壁、部屋、固定什器、通常営業の家具 |
| `print.html` / `print.css` / `print.js` | 印刷：ページ選択、A4ページ、PDF |
| `build.py` | すべてを1つのページにまとめます |
| `check-presets.mjs` | プリセットがキッチン・入口を空けているか（2Fは奥半面のみ） |
| `check.mjs` | jsdomによる動作テスト |

ソースを編集したら `python3 build.py` を実行し、commit・pushしてください。GitHub Pagesのサイトは1〜2分で更新されます。
